<h1>COURSE OBJECTIVE</h1>
<br>
The course aims to provide an understanding of analyzing algorithms and their complexity. It also allows the development of
data structures including Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming
language. Additionally, use mathematical techniques to analyze the efficiency of the various algorithms presented, as well as
the common operations on the data structures discussed. The course also allows students to implement algorithms and
conduct real-system performance measurements and analyses using the C++ programming language. This course aims to
contribute towards the attainment of SDG 9 – Industry, Innovation, and Infrastructure.
<br>
<br>
<h2>COURSE INTENDED LEARNING OUTCOMES</h2>
1. Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design <br>
2. Design efficient algorithms and analyze their complexity. <br>
3. Build efficient algorithms based on selected data structures using good programming styles in C++ <br>
